# Публичная карта с выбранными полями

Карта map4child доступна всем по ссылке; опубликованные поля можно скачать из браузера. Пользователь согласовал этот вариант для GitHub Pages: в сборку попадают только отдельно согласованные поля исходной Google-таблицы.

Ограничение доступа к исходной таблице не ограничивает доступ к данным опубликованного сайта. Согласованный состав карточки и фильтр района описаны в [договорённостях](../design.md); координаты необходимы для отображения карты и также входят в публичные данные.

Подтверждённая 11 ноября 2026 [спецификация MVP](../mvp-spec.md) расширяет публичные поля: адрес, описание, фотографии, программы, преподаватели, группы, недельное расписание, цены и начальные отзывы каталога. Черновики редактора, исходная выгрузка и пользовательские контакты в публичную сборку не входят. Контакты, записи и собственные отзывы родителя хранятся только в его браузере.

Репозиторий публичный. Готовый сайт сохраняется в ветке `gh-pages`, включая финальные данные карты; исходные и предобработанные промежуточные файлы в Git не попадают. URL исходной Google-таблицы поступает из CI-переменной. Источник читает сервисный аккаунт Google с правом «Читатель», ключ хранится в GitHub Secret. Это разделяет редактируемый источник, временные файлы сборки и опубликованный результат.

12 ноября 2026 согласовано хранить десять публичных подробных карточек и их фотографии непосредственно в `content/` исходного репозитория. Это редактируемый демонстрационный набор, описанный в [схеме каталога](../repository-catalog.md). Исходные выгрузки Sheets, черновики и пользовательские контакты по-прежнему не входят в Git. Реальные сведения двух площадок отделены от условного расписания и локальной демонстрационной записи.
