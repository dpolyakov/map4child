# Проверка MVP map4child

Дата: 11 ноября 2026. Реализация выполнена по подтверждённой [спецификации](mvp-spec.md). Этот отчёт различает локальную проверку, живые источники и незавершённые настройки.

## Проверенные результаты

- `npm run check`: TypeScript и 53 теста в 6 файлах прошли.
- Форма редактора проверена в локальном предпросмотре: добавлены второе занятие и несколько групп, проверены сообщения о незаполненных полях и сохранение черновика. Этот предпросмотр не отправляет изменения в Google и не заменяет живую приёмку.
- `npm run editor:build`: собраны Code.gs, Editor.html и манифест Apps Script. Форма и импорт используют один Zod-контракт.
- `npm run data:sync`: прочитана настоящая Google-таблица, получено 1545 точек: 1537 справочных и 8 новых демонстрационных. Сравнение с импортёром предыдущей версии на той же выгрузке показало **0 потерянных справочных точек**. Историческое число 1615 из отчёта 4 ноября не описывает текущую таблицу.
- Демонстрационные строки добавлены в существующий Пресненский лист отдельным идемпотентным скриптом; прежние ячейки не менялись. Новых листов нет.
- `npm run build`: production-сборка с каталогом `live` и проверка отсутствия конфигурации Google в `dist` прошли. Внешние изображения остались URL; закрытые черновики и сырая выгрузка в сборку не входят.
- В браузере на 1280×720 и 390×844 проверены поиск, полная карточка, выбор группы/сеанса, итоговые условия, подтверждение записи, отмена и отзыв. Перезагрузка сохранила запись; следующая форма подставила данные родителя.
- Прошедшая демонстрационная запись не открыла отзыв до отдельной отметки о посещении. Оценка без текста сохранилась; изменение и удаление обновили локальный рейтинг.
- Мобильные фильтры «9 лет + Танцы» оставили одну площадку с подходящей группой. Отключение «Можно записаться» показало 1545 точек. На OSM выбрана точка, сохранён «Дом», радиус 1 км сократил выдачу с 8 до 7 площадок. Проверены светлая и тёмная темы.
- При отказе Яндекс SDK локально включилась OSM; карта и список остались доступны.
- Ручной [workflow 43086804852](https://github.com/dpolyakov/map4child/actions/runs/43086804852) успешно выполнил build и publish для коммита `c5d5397c009535f135b85b1c2fc940d27c353133`. Новая версия доступна на [GitHub Pages](https://dpolyakov.github.io/map4child/).
- На публичном сайте проверены Яндекс Карта, 8 демонстрационных площадок, полный путь бесплатной пробной записи и её отмена. Запись выполнялась с тестовыми данными родителя. После последней публикации проверено видимое сообщение об отказе адресного поиска: HTTP Геокодер возвращает 403 и на публичном домене, при этом сама карта работает.
- Публичный [publication.json](https://dpolyakov.github.io/map4child/publication.json) доступен и содержит версии всех 8 подготовленных демонстрационных площадок; время формирования — 11 ноября 2026, 19:24 UTC.

## Незавершённые настройки

1. Войти в Google владельцем/редактором таблицы, установить привязанный Apps Script из `.generated/apps-script/` и разрешить его запуск. В доступном браузере Google не был авторизован. Сервисный аккаунт имеет доступ к ячейкам, но не заменяет авторизацию пользователя Apps Script.
2. Выбрать общую папку фотографий, предоставить сборке чтение и включить Drive API в Cloud-проекте сервисного аккаунта. До этого путь загрузки файлов не проверен; прямые внешние ссылки работают.
3. Активировать HTTP Геокодер и задать `VITE_YANDEX_GEOCODER_API_KEY` в локальном окружении и repository variables. Существующий ключ карты не прошёл пробный запрос Геокодера.

Полная приёмка MVP не заявляется до закрытия этих пунктов. Установка и контрольный сценарий описаны в [руководстве редактора](editor-guide.md).

## Отдельное замечание

Успешный workflow предупреждает об устаревающем Node.js 20 в закреплённых версиях GitHub Actions. Это не остановило публикацию; обновление версий Actions стоит выполнить отдельной задачей.
