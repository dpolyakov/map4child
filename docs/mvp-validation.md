# Проверка MVP map4child

Дата: 11 ноября 2026. Реализация выполнена по подтверждённой [спецификации](mvp-spec.md). Этот отчёт различает локальную проверку, живые источники и незавершённые настройки.

## Проверенные результаты

- `npm run check`: TypeScript и 55 тестов в 6 файлах прошли.
- Форма редактора проверена в локальном предпросмотре: добавлены второе занятие и несколько групп, проверены сообщения о незаполненных полях и сохранение черновика. Этот предпросмотр не отправляет изменения в Google и не заменяет живую приёмку.
- `npm run editor:build`: собраны Code.gs, Editor.html и манифест Apps Script. Форма и импорт используют один Zod-контракт.
- По уточнению пользователя загрузка файлов удалена из формы, серверных функций и импорта. Повторно прошли 53 теста, сборка редактора, импорт 1545 точек и production-сборка. Все три обновлённых файла сохранены в Google; манифест содержит только текущую таблицу, окно формы и внешние запросы, без разрешений Drive.
- В локальном предпросмотре обновлённой формы проверены отказ некорректной ссылки, добавление доступного изображения, предпросмотр, подпись, подготовка и удаление фото. Сохранение в настоящую таблицу по-прежнему требует отдельной живой проверки после авторизации.
- После входа пользователя три файла сохранены в [привязанном проекте Apps Script](https://script.google.com/u/0/home/projects/1k-dQ6uXspSySxTBscMyRqUjAOBlc-HP9WTEg9cYUTvy5xjv3e_6Qq-bi/edit) «map4child — редактор каталога». Запуск `onOpen` дошёл до запроса разрешений Google; успешное выполнение пока не подтверждено.
- Пользователь остановился на предупреждении Google с чужим адресом разработчика. Проверка окна доступа подтвердила: исходная таблица принадлежит внешнему владельцу и открыта на редактирование всем по ссылке. Привязанный скрипт наследует это владение и доступ. Авторизация не подтверждена. После этого пользователь исключил загрузку файлов: редактор оставлен в исходной таблице, доступ к Drive удалён; владение и общие права таблицы не менялись.
- При установке воспроизведено отклонение корректного фото в V8-контексте без `URL`. Добавлена серверная реализация URL из core-js и проверка собранного файла внутри `editor:build`; после исправления эта проверка и все 53 теста прошли. Обновлённый Code.gs сохранён в Google.
- `npm run data:sync`: прочитана настоящая Google-таблица, получено 1545 точек: 1537 справочных и 8 новых демонстрационных. Сравнение с импортёром предыдущей версии на той же выгрузке показало **0 потерянных справочных точек**. Историческое число 1615 из отчёта 4 ноября не описывает текущую таблицу.
- Демонстрационные строки добавлены в существующий Пресненский лист отдельным идемпотентным скриптом; прежние ячейки не менялись. Новых листов нет.

## Незавершённые настройки

1. Проверить сокращённые разрешения установленного Apps Script и разрешить его запуск, затем выполнить живую проверку формы. Скрипт запрашивает текущую таблицу, окно формы и внешние запросы; доступа к Google Drive нет. Владелец и общие права исходной таблицы не менялись.
2. Активировать HTTP Геокодер и задать `VITE_YANDEX_GEOCODER_API_KEY` в локальном окружении и repository variables. Существующий ключ карты не прошёл пробный запрос Геокодера.

Полная приёмка MVP не заявляется до закрытия этих пунктов. Установка и контрольный сценарий описаны в [руководстве редактора](editor-guide.md).

## Отдельное замечание

Успешный workflow предупреждает об устаревающем Node.js 20 в закреплённых версиях GitHub Actions. Это не остановило публикацию; обновление версий Actions стоит выполнить отдельной задачей.
