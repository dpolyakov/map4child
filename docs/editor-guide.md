# Редактор каталога map4child

Статус на 11 ноября 2026: три файла сохранены в [привязанном проекте Apps Script](https://script.google.com/u/0/home/projects/1k-dQ6uXspSySxTBscMyRqUjAOBlc-HP9WTEg9cYUTvy5xjv3e_6Qq-bi/edit) «map4child — редактор каталога». Первый запуск ожидает разрешений Google; работа формы в настоящей таблице ещё не проверена. Сайт читает только подготовленные версии.

## Однократная установка

1. Выполнить `npm run editor:build` в репозитории. Сборка создаст `.generated/apps-script/Code.gs`, `Editor.html` и `appsscript.json`.
2. В исходной Google-таблице открыть «Расширения → Apps Script». Это должен быть проект, привязанный к этой таблице.
3. Поместить содержимое `Code.gs` в одноимённый файл проекта. Создать HTML-файл `Editor` и поместить туда содержимое `Editor.html`. В настройках проекта включить отображение манифеста и заменить `appsscript.json` подготовленным файлом.
4. Сохранить проект, выполнить `onOpen`, затем обновить таблицу. Появится меню «map4child». Развёртывание веб-приложения не требуется.
5. При первом запуске владелец проверяет и разрешает доступ скрипта. Манифест запрашивает текущую таблицу, окно редактора, Drive для файлов общей папки и внешние запросы для проверки опубликованной версии. Стандартный `DriveApp` требует общий scope Drive; сам код работает только с выбранной папкой. Авторизацию выполняет владелец.
6. Создать или выбрать общую папку фотографий. Дать редакторам запись, сервисному аккаунту сборки — чтение. Выбрать «map4child → Настроить папку фотографий» и указать ссылку на папку. Идентификатор хранится в свойствах привязанного документа.
7. В Google Cloud-проекте сервисного аккаунта включить Google Drive API. При первой проверке API 11 ноября вернул `403 accessNotConfigured`. Google Sheets API и доступ к таблице уже работают.
8. Открыть форму и выполнить живую проверку из раздела ниже. До неё установка не считается завершённой.

Файлы уже установлены в исходную таблицу; для продолжения нужен шаг 5. При открытии Google Cloud Console текущий аккаунт также потребовал повторного подтверждения личности перед настройкой Drive API.

Для обновления установленного редактора повторить сборку и заменить три файла. Служебные столбцы и данные таблицы сохраняются.

## Работа команды

Выберите региональный лист, затем строку площадки и «map4child → Редактировать площадку». Для нового адреса используйте «Добавить площадку».

Заполняйте обычные поля. Кнопки добавляют фотографии, занятия, группы, интервалы расписания, абонементы и начальные отзывы. Поле «Цена пробного» принимает 0 для бесплатного занятия; пустое значение означает неизвестную цену. Места задаются отдельно для каждого сеанса. Даты ближайших 28 дней сайт строит из недельного расписания по Москве.

У многоадресной строки выберите нужную точку. Подробная карточка этого филиала попадёт в новую строку того же листа и дополнит прежнюю точку без дубля. Остальные адреса сохранятся как справочные.

- **Сохранить черновик** — сохранить незавершённые поля. Сборка и текущий сайт продолжают использовать прежнюю подготовленную версию.
- **Проверить поля** — увидеть, что мешает подготовке.
- **Подготовить к публикации** — проверить активные занятия и группы и сохранить снимок для следующей сборки.
- **Убрать с сайта / Вернуть на сайт** — подготовить состояние площадки для следующей ручной публикации. Строка не удаляется.
- **Загрузить актуальную версию** — перечитать карточку после чужого изменения. Перед заменой несохранённых полей форма предупреждает.

Статус опубликованной версии определяется файлом `publication.json` с публичного сайта. Если сайт не удалось проверить, форма сообщает об этом и не утверждает, что публикация состоялась. Новые черновики могут существовать одновременно с опубликованной подготовленной версией.

Внешняя фотография должна быть прямой ссылкой на изображение. Форма показывает предпросмотр; копий такого файла не создаёт. Загружаемые с компьютера JPG, PNG, WebP и GIF до 10 МБ сохраняются в общей папке; сборка читает только файлы подготовленных карточек и публикует их в `media/`.

## Ручное обновление сайта

Откройте [Update map](https://github.com/dpolyakov/map4child/actions/workflows/publish.yml), выберите нужную ветку и нажмите Run workflow. Для обычной работы используется `main`.

Проверьте завершение обоих jobs: build и publish. Затем обновите [публичный сайт](https://dpolyakov.github.io/map4child/) и откройте изменённую площадку. Сохранение, подготовка и редактирование ячеек не запускают workflow автоматически.

Ошибочная подготовленная карточка или недоступное фото Drive останавливают сборку; прежний сайт остаётся доступен. Не редактируйте служебные JSON-столбцы вручную.

## Проверка после установки

Создать тестовую площадку с двумя занятиями и несколькими группами. Сохранить неполный черновик, закрыть и открыть снова. Подготовить полную версию; затем изменить только черновик и убедиться, что подготовленная версия прежняя. Открыть карточку у двух редакторов и проверить конфликт сохранения. Загрузить один файл и вставить одну внешнюю ссылку. Выполнить ручную публикацию, сверить карточку и статус формы. Снять площадку с публикации и вернуть её следующими ручными обновлениями.

## Контракт и исходники

- Поля и проверки: `shared/marketplace-model.ts` — один контракт для формы, серверной части Apps Script и импорта.
- Сохранение, блокировка и работа с Drive: `apps-script/server.ts`.
- Форма: `apps-script/client.tsx`; внешние функции меню: `apps-script/wrappers.gs`.
- Серверная сборка включает реализацию `URL` из core-js: [Apps Script V8 не предоставляет этот API](https://developers.google.com/apps-script/guides/v8-runtime). `editor:build` проверяет готовый серверный файл в отдельном V8-контексте без браузерных API.
- Служебные столбцы: `M4C_ID`, `M4C_DRAFT`, `M4C_READY`, `M4C_REVISION`, `M4C_NEW`. Добавляются справа и скрываются; новые листы не создаются.
- `M4C_NEW` скрывает новые строки от справочного импорта до подготовки карточки. `M4C_READY` содержит опубликованный контракт; `M4C_DRAFT` не входит в сборку.
- Размер снимка ограничен 49 000 символов на ячейку. При превышении форма просит сократить текст; данные не обрезаются.
- Демонстрационные площадки добавляются идемпотентно через меню редактора или `scripts/seed-demo.ts`. Это явное действие подготовки данных, не автоматический шаг публикации.

Основание механизма: [диалоги Google Apps Script](https://developers.google.com/apps-script/guides/dialogs). Границы MVP и критерии: [спецификация](mvp-spec.md).
