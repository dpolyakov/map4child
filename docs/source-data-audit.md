# Исходные данные map4child

Проверено 3 ноября 2026 года. Статус: исследование исходных данных; принятые решения отдельно отмечены ниже и сведены в [договорённости](design.md).

Источник — Google-таблица «Карта кружков»; по решению Q10 её URL передаётся через CI-переменную и не фиксируется в документации проекта. Проверка выполнена через интерфейс и копирование ячеек без изменений. Таблица открылась без входа; доступ из GitHub Actions через Sheets API не проверен. Скрытые листы через API не проверялись.

Пять реестров содержат 1 609 строк. Это число строк, а не число уникальных организаций, площадок или программ. Общие поля A:G: название студии, район, адрес, тип партнёра, массовость, частный или государственный, специальность.

## Что требует обработки

- Явные координаты есть у 192 строк. Семь строк содержат несколько пар через `;`: всего 208 пар, 182 уникальные пары при округлении до шести знаков. Проверка наличия координат не подтверждает их точность на местности.
- Текущий формат координат — `широта, долгота`, десятичный разделитель — точка; несколько пар разделены `;`, пробелы могут присутствовать. Синтетический пример формата: `55.75, 37.60; 55.76, 37.61`.
- Одна строка может описывать организацию с несколькими адресами; занятия одной площадки иногда занимают отдельные строки. По уточнению после Q10 уникальная [точка карты](../GLOSSARY.md) определяется названием и координатами; несколько пар координат в строке создают несколько точек.
- Разные организации могут иметь одинаковые координаты. Удалять такие записи как дубли нельзя.
- Категории требуют согласованного словаря: встречаются `Спорт`/`спорт`, `ИТ/инженеры`/`ИТ`, `Творчество/искусство`/`Творчество/исскуство`/`творчество и искусство`; есть `Иностранные языки`.
- Тип партнёра бывает многозначным. «Массовость» местами пустая; в ЮЗАО одна строка без значения «Частный или гос».
- Название листа не задаёт район записи: лист Мневников включает восемь районов.
- Отдельных полей возраста, цены, расписания, постоянного идентификатора и статуса публикации нет.
- В проверенных примерах источников URL записаны явным текстом; несколько ссылок могут быть разделены переводами строк. Сохранённые данные подтверждают это для просмотренных примеров, но не доказывают отсутствие ссылок с произвольной текстовой подписью во всех ячейках; чтение через Sheets API ещё не проверялось.

Точных повторов всей строки или сочетания «название + адрес» внутри каждого листа не обнаружено; семантическое сравнение дублей и межлистовая сверка не выполнялись. В скопированных диапазонах реестров признаков объединённых ячеек не найдено.

## Один лист или несколько

Ради скорости единый лист не требуется: Sheets API позволяет сначала получить свойства листов через [`spreadsheets.get`](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets/get), затем прочитать диапазоны разных листов одним [`values.batchGet`](https://developers.google.com/workspace/sheets/api/samples/reading#read_multiple_ranges_across_multiple_sheets). Для текущей схемы это обычно два запроса на обновление; фактическая скорость не измерялась.

Согласовано в Q5–Q6: читать все пять текущих листов с данными по явному списку, преобразовывать их столбцы в общую схему и собирать набор данных для сайта. Служебный лист «Промпт» не включать. Браузер получает результат сборки; число исходных вкладок не определяет скорость загрузки карты.

Подготовка нужна прежде всего для разбора нескольких координат, согласования категорий и отбора полей для публикации. Согласовано в Q6: строки без координат пропускаются, остальные могут публиковаться; пользователь поручает подготовку координат отдельному агенту.

В «Массовости» встречаются `Сеть`, `Франшиза`, `Частная`, `частная студия`, `одиночное учреждение`, `Не известно` и пустые значения. По уточнению пользователя к Q13 исходный enum — `Сеть | Франшиза | Частная`; остальные и пустые значения отображаются как «Нет данных». В Q12 пользователь также подтвердил, что «Мульти» — обычная самостоятельная категория специальности. Полные правила — в [договорённостях](design.md).

## Существующий пример

Локальный `example.html` — отдельный прототип на Leaflet со встроенными данными от 31 октября 2026 года: 1 007 строк-программ, 1 003 строки с координатами, 295 уникальных координат. Эти числа и схема отличаются от текущей Google-таблицы; пример нельзя автоматически считать её актуальной выгрузкой.

В примере есть фильтры и карточки, но нет чтения Sheets и подключения Яндекс Maps SDK. Группировка работает только для полностью совпадающих координат. В Q9 пример принят как визуальный ориентир; его встроенный набор данных актуальным источником не является.
